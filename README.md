# ATTCaveSeedUtility
This mod allows you to get and set your cave seed.
This mod only needs to be on the server side.
## How To Use
Add the CaveSeedUtil.dll to your server, then open the console through the TavernLauncher and use the following commands :  
-***caveseed get***  
-***caveseed set [int]***  
*(These commands can also be found through the help commands in the console)*  
ints for the set command **must** be positive.
